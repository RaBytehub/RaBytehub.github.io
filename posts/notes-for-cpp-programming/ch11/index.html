11. io Files

输入/输出文件

本章整理 C++ 控制台输入输出、格式控制、文本文件读写和二进制文件读写。

基于控制台的输入/输出

控制台输入可以用>>, get, getline，控制台输出可以用<<, put

无格式输出

图示转写：put 输出字符

ostream::put 用于向输出流写入一个字符，并返回当前输出流对象，因此可以连续调用：

cout.put('A').put('\n');
cout.put(65);   // ASCII 码 65 对应字符 A

图示转写：write 无格式输出

ostream::write 按指定长度输出字符序列，不会因为遇到空格或 \0 自动停止：

char buffer[] = "HAPPY BIRTHDAY";
cout.write(buffer, 10);                 // HAPPY BIRT
cout.write("ABCDEFGHIJKLMNOPQRSTUVWXYZ", 10); // ABCDEFGHIJ

int x = 5;
cout.write(reinterpret_cast<char*>(&x), sizeof(x));

最后一种写法用于二进制输出，直接写出变量在内存中的字节。

无格式输入

图示转写：read 无格式输入

istream::read 从输入流读取指定数量的字节到缓冲区：

char buffer[80];
cin.read(buffer, 10);
cout.write(buffer, cin.gcount());

读取二进制数据时常见写法如下：

int x;
cin.read(reinterpret_cast<char*>(&x), sizeof(x));

gcount() 可以取得上一次无格式输入实际读取的字符数。

格式化输入/输出：

  1. 设置整型数的基数

    #include <iomanip>
// hex: 16
// oct: 8
// dec: 10
cin >> oct >> n; // 表示读入八进制的整数
cout << hex << n; // 表示输出十六进制的整数
cout << setbase(8) << n; // 表示输出八进制的整数

  2. 设置浮点数的精度

    #include <iomanip>
for (int i = 9; i > 0; --i)
{
    cout.precision(i);
    cout << x << '\t' << y << endl;
}
// 或者写成
for (int i = 9; i > 0; --i)
cout << setprecision(i) << x << '\t' << y << endl;

  3. 设置域宽

    #include <iomanip>
//setw(NUM) 设置域宽
//setfill('CHAR') 设置填充字符
cout << setw(5) << 123 << endl;
cout << setw(5) << setfill('#') << 123 << endl;
cin >> setw(5) >> a >> setw(5) >> b; //注意有'\0'

  4. 自定义输入流操纵符

基于文件的输入/输出

文件与流：

C++语言把每一个文件都看成一个有序的字节流 把文件看成 n 个字节 每一个文件以文件结束符(end-of-file marker)结束 C++用输入输出流对象来访问文件 当程序要从文件中读取数据时，将文件与一个输入文件流(ifstream)对象关联 当程序要将数据写入一个文件时，将文件与一个输出文件流(ofstream)对象关联 如果既要从一个文件读取也要存入数据至该文件，将文件与一个输入/输出文件流(fstream)对象相关联

图示转写：文件访问过程

文件读写的一般步骤：

  1. 定义文件流对象，例如 ifstream、ofstream、fstream。
  2. 打开文件，把文件流对象和磁盘文件关联起来。
  3. 读写文件内容。
  4. 关闭文件，解除流对象和文件的关联。

常用类型：

类型用途
ifstream输入文件流，用于读文件
ofstream输出文件流，用于写文件
fstream输入输出文件流，可读可写

访问一个文件由4个步骤组成：

  1. 定义一个文件流对象
  2. 打开文件
  3. 操作文件中的数据
  4. 关闭文件

文件打开

//=====打开输入文件=====
ifstream infile; 
infile.open("file1");//必须存在文件名为file1的文件
infile.open("file1", ifstream::in);
//也可以利用构造函数直接打开（定义对象时自动调用构造函数）：
ifstream infile("file1");
ifstream infile("file1", ifstream::in);

//=====打开输出文件=====
ofstream outfile; 
outfile.open("file2");//若不存在，则创建file2,若存在则清空
outfile.open("file2", ofstream::out); 
//也可以利用构造函数直接打开：
ofstream outfile("file2");
ofstream outfile("file2", ofstream::out);  

//=====打开输入输出文件=====
fstream iofile; 
iofile.open("file3");//若不存在file3，无法创建，会报错
iofile.open("file3", fstream::in|fstream::out); 
//也可以利用构造函数直接打开
fstream iofile("file3");//若不存在file3，无法创建，会报错
fstream iofile("file3", fstream::in|fstream::out);

文件关闭

对象名.close();
//main函数执行结束时，会关闭所有打开的文件

文件的顺序访问

图示转写：顺序访问文件

文本文件可以像控制台一样使用 >>、<< 进行顺序读写。检测文件是否打开成功可以使用流对象本身，读到文件末尾后也可以用读取表达式判断循环是否继续：

ifstream in("file1");
int x;
while (in >> x) {
    cout << x << ' ';
}

相比 while (!in.eof())，直接把读取操作放进循环条件更可靠。

方法一（文本文件、ASCII文件）

代码转写：向文本文件写入数据

#include <fstream>
#include <iostream>
using namespace std;

int main()
{
    ofstream out("file.txt");
    if (!out) {
        cerr << "create file error\n";
        return 1;
    }

    for (int i = 0; i <= 10; ++i) {
        out << i << ' ';
    }

    out.close();
    return 0;
}

方法二（二进制文件）

代码转写：二进制文件 write/read

使用 write 写入二进制数据，使用 read 读取二进制数据：

#include <fstream>
#include <iostream>
using namespace std;

int main()
{
    ofstream out("file", ios::binary);
    if (!out) {
        cerr << "create file error\n";
        return 1;
    }

    for (int i = 1; i <= 10; ++i) {
        out.write(reinterpret_cast<char*>(&i), sizeof(i));
    }
    out.close();

    ifstream in("file", ios::binary);
    int x;
    while (in.read(reinterpret_cast<char*>(&x), sizeof(x))) {
        cout << x << ' ';
    }
}

文件的随机访问

读文件定位指针：tellg

写文件定位指针：tellp

设置写文件的位置：seekg

设置读文件的位置：seekp

7. Pointers and References

指针

指针变量 p 占用内存的大小，不取决于类型变量的大小，而是系统架构：

32位系统：4 字节

64位系统：8 字节

指针的访问——解引用

NULL/nullptr是一个特殊指针值，称为空指针值为0，可被用来初始化一个指针，表示不指向任何地址，不能解引用空指针

没有初始化的指针可能指向任意地址，对这些指针作解引用可能导致难以意料的错误

统配指针类型void* 的特点：

  • 可以存储任何类型的地址（int*、char*、double*、对象指针等）
  • 使用时需要强制类型转换才能解引用或操作
  • 任何类型的指针都可以给void类型的指针赋值

指针与常量限定符const

常量指针：

const int *p;

指针常量：

int * const p;

指向常量的常量指针：

const int * const p;

指针运算

指针运算 指针的加减法考虑指针的基类型

对指针变量p加1，p的值增加了一个基类型的长度

用指针访问数组

数组名保存了数组的起始地址，它是一个指针常量，值不能变

如执行了p = array，array是array[0]的地址，则*p与array[0]是等价的

如果指针p指向数组array的第k个元素，那么p+i指向第k+i个元素，p-i指向第k-i个元素，那么可以用*(array+k)表示array[k]

*(p + k)为p的值 + k * sizeof(*p)，*(p - k)为p的值 - k * sizeof(*p)

用指针遍历数组的五种方式：

int i;
int *p;
for(i = 0; i < 5; i++) cout << array[i] << endl;
for(i = 0; i < 5; i++) cout << *(array+i) << endl;
for(p = array; p < array + 5; p++) cout << *p << endl;
for(p = array, i = 0; i < 5; i++) cout << *(p + i) << endl;
for(p = array, i = 0; i < 5; i++) cout << p[i] << endl;

数组和指针是不同的，最根本的区别在于内存的分配：1. 定义数组：所有存放数组元素的空间；2. 定义指针：一个储存地址的空间

字符串再讨论

char ch[] = {'H', 'e', 'l', 'l', 'o', '!', 'o', '\0'};
char ch[] = {"Hello!"};
char ch[] = "Hello!";

第一种是直接在栈区域中对字符串数组直接赋值，第二、三种是在常量区域中将每个字符拷贝到栈区域中

图示转写：字符数组与字符串常量

C 风格字符串本质上是以空字符 \0 结尾的字符数组。常见形式：

const char* s1 = "abcde";
char s2[] = "abcde";

s1 指向字符串常量，内容通常不可修改；s2 是字符数组，会复制出一份可修改的字符序列。

常量、堆、栈

图示转写：指向字符串常量的指针

const char* str = "abcde";

这条语句让 str 指向字符串常量 "abcde" 的首地址。改变 str 的指向是允许的，但不能通过 str 修改字符串常量的内容。

图示转写：指向字符数组的指针

char ch[6] = "abcde";
char* str = ch;

此时 str 指向数组 ch 的首元素。因为 ch 是普通字符数组，所以可以通过 str 修改数组中的字符。

图示转写：动态字符数组

char* str = new char[6];
strcpy(str, "abcde");
delete[] str;

动态申请的字符数组位于堆区。使用 strcpy 前必须保证目标空间足够容纳所有字符和结尾的 \0，用完后要用 delete[] 释放。

三种类型：指针指向常量字符串；指针指向数组；常量拷贝至新的内存空间，指针指向新的内存区域

cout输出指向数组地址的指针意味着从指定的地址开始一直输出直到遇到'\0'

指针与函数

函数传递的三种方式：值传递、指针传递、引用传递

指针作为形式参数

用指针作为参数可以在函数中修改调用该函数的函数中的变量值。

输入参数一般用值传递，而输出参数可以用指针传递。在设计函数原型时，一般将输入参数放在前面，输出参数放在后面。

输入——函数参数用指针，调用函数时用地址

输出——输出参数可以用指针传递

e.g. 解一元二次方程

数组作为函数参数

数组传递时，形式参数和实际参数实际上共享了同一块存储空间。函数内对形式参数的修改实际上都是对实际参数的修改。

#include <iostream>
using namespace std;

void p(int arr[]);
int main()
{
   int array[] = {1, 2, 3, 4, 5};
   cout << sizeof(array) << endl; 
   p(array);
   return 0;
}
void p(int arr[])
{
   cout << sizeof(arr) << endl;
}
  • 关键：C++中，数组作为函数参数时，会自动退化(decay)成指针
  • int arr[]作为参数，编译器实际上把它当成int* arr
  • 所以arr是一个指针变量，不是数组
  • sizeof(arr)计算的是指针本身的大小：
    • 64位系统：8字节
    • 32位系统：4字节

真实情况：

#include <iostream>
using namespace std;

void p(int* arr);
int main()
{
   int array[] = {1, 2, 3, 4, 5};
   cout << sizeof(array) << endl; // Output: 20 (size of the entire array in bytes)
   p(array);
   return 0;
}
void p(int* arr)
{
    cout << sizeof(arr) << endl; 
}

重要结论：一旦数组作为参数传递，就丢失了它的大小信息，因此，在C++中传递数组时，通常需要额外传递一个长度参数。

#include <iostream>
using namespace std;

void minmax(int a[], int n, int *min_ptr, int *max_ptr)
{
   int min1, max1, min2, max2;

   if (n == 1)
      *min_ptr = *max_ptr = a[0];
   else
   {
      minmax(a, n / 2, &min1, &max1);             // 找前一半的最大最小值
      minmax(a + n / 2, n - n / 2, &min2, &max2); // 找后一半的最大最小值
      if (min1 < min2)
         *min_ptr = min1;
      else
         *min_ptr = min2;
      if (max1 < max2)
         *max_ptr = max2;
      else
         *max_ptr = max1;
   }
}

int main()
{
   int n;
   cin >> n;
   int *arr = new int[n];
   for (int i = 0; i < n; i++)
   {
      cin >> arr[i];
   }
   int min, max;
   minmax(arr, n, &min, &max);
   cout << "Min: " << min << ", Max: " << max << endl;
   delete[] arr;
   return 0;
}

字符串作为函数参数

统计单词数量

#include <iostream>
using namespace std;

int count(const char *s) // 限定函数不可以修改s指向的单元值
{
    int cnt = 0;
    while (*s != '\0')
    { //   遍历字符串
        while (*s == ' ')
            ++s; // 跳过空白字符
        if (*s != '\0')
        { // 找到一个单词
            ++cnt;
            while (*s != ' ' && *s != '\0')
                ++s; // 跳过单词
        }
    }
    return cnt;
}

int main()
{
    char str[100];
    cin.getline(str, 100);
    cout << count(str) << endl;
    return 0;
}

返回指针的函数

#include <iostream>
#include <cstring>
using namespace std;

char *subString(const char *s, int start, int end)
{
   int len = strlen(s);
   if (start < 0 || start >= len || end < 0 || end >= len || start > end)
   {
      cout << "起始或终止位置错" << endl;
      return nullptr;
   }
   char *sub = new char[end - start + 2]; // 为子串准备空间
   strncpy(sub, s + start, end - start + 1);
   return sub;
}

图示转写：返回指针的函数

函数可以返回指针，但不能返回指向局部变量的指针，因为局部变量在函数结束后就失效了。安全做法是返回动态分配的内存或让调用者传入缓冲区：

char* substr(const char* s, int start, int end)
{
    int len = end - start + 1;
    char* sub = new char[len + 1];
    strncpy(sub, s + start, len);
    sub[len] = '\0';
    return sub;
}

最好用动态变量

代码转写：取出字符串子串

下面的函数从字符串中复制 [start, end] 区间的字符，返回新字符串：

char* substr(const char* s, int start, int end)
{
    int len = strlen(s);
    if (start < 0 || start >= len || end < 0 || end >= len || start > end) {
        return nullptr;
    }

    char* sub = new char[end - start + 2];
    strncpy(sub, s + start, end - start + 1);
    sub[end - start + 1] = '\0';
    return sub;
}

int main()
{
    char* ans = substr("Hello world", 2, 5);
    cout << ans << endl;
    delete[] ans;
}

注意：调用者拿到动态分配的数组后，必须负责释放。

引用类型

函数参数的引用传递

引用传递是地址传递的另一种更简单明了的实现方法

相对于Copy-by-Value，利用引用传递（Copy-by-Reference）的好处是减少函数调用时的开销，不需要分配新的内存空间，不需要复制实际参数的数值

如果在函数内不许改变参数的值，则形式参数用const限定

对const的参数采用引用传递时，实际参数不能是常量

#include <iostream>
using namespace std;

int &max(int &a, int &b, int &c)
{
    if (a > b)
    {
        if (a > c)
            return a;
        else
            return c;
    }
    else if (b > c)
        return b;
    else
        return c;
}

int &min(int &a, int &b, int &c)
{
    if (a < b)
    {
        if (a < c)
            return a;
        else
            return c;
    }
    else if (b < c)
        return b;
    else
        return c;
}

void swap(int &a, int &b)
{
    int c;
    c = a;
    a = b;
    b = c;
}

int main()
{
    int x = 2, y = 4, z = 6;
    cout << "before swap: x=" << x << ", y=" << y << ", z=" << z << endl;
    swap(max(x, y, z), min(x, y, z));
    cout << "after swap: x=" << x << ", y=" << y << ", z=" << z << endl;
    return 0;
}

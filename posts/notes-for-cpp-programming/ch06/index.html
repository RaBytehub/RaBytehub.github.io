函数调用的过程

发生函数调用时： 1）为被调用函数的形参和局部变量分配空间，称作帧 2）计算每个实际参数值，并将实际参数赋值给形式参数，称作参数传递 传递方式：值传递，即求出实参的值并赋值给形参变量，函数中对形参的修改不影响实参（单向传递，实参→形参）

执行被调用函数体： 1）保护调用函数现场，控制转入被调用函数，执行函数体的每个语句 2）当执行return语句或函数体结束时，控制将从函数返回

从函数返回时： 1）计算return后面的表达式的值，控制返回到调用函数 2）用函数返回值初始化一个临时变量，置换本次函数调用 3）自动收回分配给被调用函数的内存 4）继续调用函数main后续语句的执行

数组参数的传递机制

图示转写：数组参数的传递机制

数组作为函数参数时，形参接收到的是数组首元素的地址，而不是整个数组的副本。因此：

int average(int arr[10]);
int average(int arr[]);
int average(int* arr);

这三种写法在函数形参中等价。由于函数只拿到首地址，数组长度不会自动传入，通常需要额外传递一个长度参数：

int sumArray(const int arr[], int size)
{
    int sum = 0;
    for (int i = 0; i < size; ++i) {
        sum += arr[i];
    }
    return sum;
}

变量的作用域

全局变量与局部变量

编译器如何确定一个名字到底引用的是哪个变量？ 编译器保存一个所有全局声明的标识符表 编译器为每个作用域都保存一个局部声明的标识符表 当碰到一个标识符时，先查当前作用域的标识符表，再查外部作用域表（如果存在的话），最后查全局标识符表

局部变量与全局变量同名：局部变量屏蔽全局变量，如果要使用全局变量，可以使用作用域运算符::

在一个函数内的复合语句中定义的变量在本复合语句范围内有效，如for循环

#include<iostream>
using namespace std;

int strinstr(char a[], char b[])
{
    int i, j;
    for (i = 0; a[i] != '\0'; i++)
    {
        for (j = 0; b[j] != '\0'; j++)
        {
            if (a[i + j] == '\0' || a[i + j] != b[j])
                break;
        }
        if (b[j] == '\0')
            return i;  
    }
    
    return -1;  
}

int main()
{
    char a[100], b[100];
    cin.getline(a, 100);
    cin.getline(b, 100);
    
    cout << strinstr(a, b) << endl;
    
    return 0;
}

变量的存储类别

分为自动变量（auto）、静态变量（static）、寄存器变量（register）、外部变量（extern），变量的存储类别的核心在于它的存储位置

图示转写：程序内存分区

程序运行时常见的内存区域包括：

区域存放内容
栈 stack函数形参、局部变量，生命周期通常随函数调用结束而结束。
堆 heap通过 new 动态申请的内存，需要用 delete 释放。
全局/静态存储区全局变量、静态变量，生命周期贯穿整个程序运行期。
常量存储区字符串字面量等常量数据。
代码区 text程序指令。

静态变量

图示转写：静态变量 static

static 修饰的局部变量只在定义语句第一次执行时初始化一次，随后一直保存在静态存储区中，直到程序结束。

void counter()
{
    static int n = 0;
    ++n;
    cout << n << endl;
}

如果连续调用 counter() 三次，会输出 1 2 3。这说明 n 的生命周期贯穿程序运行期，但作用域仍限制在函数内部。

寄存器变量 (register)

寄存器变量用register声明，直接将一个变量保存在CPU的寄存器中

只有局部变量（自动）可以声明为寄存器变量，全局变量和静态局部变量不能存储在寄存器中

若系统无合适的寄存器可用，则编译器将它转化为自动变量

外部变量 (extern)

同一源文件中，引用了之后才定义的全局变量也需要用extern声明（记住：引用永远出现在声明之后）

变量的内存分配

图示转写：变量的内存分配

函数的形参和局部变量通常分配在栈区；动态申请的对象位于堆区；全局变量和静态变量位于全局/静态存储区。作用域决定变量"在哪里能被访问"，生命周期决定变量"什么时候存在"，两者不是同一个概念。

递归函数

解决汉诺塔问题的函数：

#include <iostream>
using namespace std;

void Hanio(int n, char start, char end, char temp)
{
    if (n == 1)
    {
        cout << start << "->" << end << endl;
    }
    else
    {
        Hanio(n - 1, start, temp, end);
        cout << start << "->" << end << endl;
        Hanio(n - 1, temp, end, start);
    }
}

int main()
{
    Hanio(10, 'A', 'C', 'B');
    return 0;
}

任务描述 本关任务：给定长度为n的字符串S，S只包含小写英文字母，按如下规则构造长度为n的字符串T 1）初始情况T是空串 2）如果S头部的字符小于尾部的字符，从S的头部删除一个字符，将其加到T的尾部 3）如果S尾部的字符小于头部的字符，从S的尾部删除一个字符，将其加到T的尾部 3）如果S尾部的字符等于头部的字符，从S的尾部或者头部删除一个字符，将其加到T的尾部 多次重复2）3）4），最后得到T，但T的内容取决于操作序列中步骤2和步骤3 步骤4的顺序，现在的目标是构造字典序最小的T 例如：S=“acdbcb”，则T=“abcbcd”

编程要求 根据提示，在右侧编辑器补充代码，输入字符串S（长度小于80），计算并输出字典序最小的字符串T

测试说明 平台会对你编写的代码进行测试：

测试输入：acdbcb 预期输出： abcbcd

任务描述 本关任务：计算无重复字符的最长子串的长度

编程要求 根据提示，在右侧编辑器补充代码，用户输入字符串s（都是小写字母），找出该字符串中无重复字符的最长子串的长度

测试说明 平台会对你编写的代码进行测试：

测试输入： abcabcbb

预期输出： 3 解释：最长的无重复字符的子串为abc/bca/cab，长度为3

提供一种思路 定义一个整型数组int a[26]={0}用来对现有字符计数，当前遍历的字符出现一次，a[字符对应的整数]=1； 两层for循环，第一层遍历字符串，第二层，当前字符和以后所有的字符比较，不相等且a[后面的字符对应的整数]==0（证明该字符还没有在当前子串中出现过）时记录当前不重复子串长度。第一层循环中不断更新最长的子串长度

#include <iostream>
#include <cstring>
using namespace std;
int maxlensub(char s[])
{
    int maxlen = 0;
    for(int i = 0; s[i] != '\0'; i++)
    {
        int a[26] = {0};
        int len = 0;
        for (int j = i; s[j] != '\0'; j++)
        {
            if(a[s[j]-'a'] == 0) 
            {
                a[s[j]-'a'] = 1;
                len++;
            }
            else break;
        }
        if (len > maxlen) maxlen = len;
    }
    return maxlen;
}
int main()
{
    char s[100];
    cin.getline(s,100);
    cout<<maxlensub(s);
    return 0;
}

参数传递方式对比

方式示例特点
值传递void f(int x)函数得到副本，不影响实参。
指针传递void f(int* p)可以通过地址修改实参，需要判空。
引用传递void f(int& x)写法像普通变量，但会影响实参。
常量引用void f(const T& x)避免拷贝，同时禁止修改实参。

# 创建新的类型

> 这一章开始进入面向对象编程，重点是类、对象、构造函数、析构函数、拷贝构造、`const`、静态成员和友元。

## 对象

### this指针

### 图示转写：`this` 指针

成员函数被某个对象调用时，编译器会把该对象的地址作为隐藏参数传入，这个隐藏参数就是 `this` 指针。它指向当前调用成员函数的对象。

```cpp
void create(int n, int d)
{
    this->num = n;
    this->den = d;
}
```

当形参与成员变量同名时，`this->成员名` 可以明确表示访问的是对象成员。

### 代码转写：返回当前对象

成员函数可以返回 `*this`，常用于链式调用：

```cpp
Rational mod(int n, int d)
{
    num = num + n;
    den = den + d;
    return *this;
}
```

通常为了避免对象拷贝，实际工程中更常写成返回引用：`Rational& mod(int n, int d)`。

## 拷贝构造函数

参数传递能否是值传递？不能。

系统有缺省的复制构造函数么？有。

如果没有显示定义，编译器自动生成一个默认复制构造函数，它将实参对象的数据成员逐字节拷贝给正在创建对象的数据成员

```c++
class point
{
    int x, y;

public:
    point(int a, int b)
    {
        x = a;
        y = b;
    }
    point(const point &p)
    {
        x = 2 * p.x;
        y = 2 * p.y;
    }
}
```

**自动调用复制构造函数：**

（1）新对象定义时

```c++
DoubleArray array2(array1);      
//OR
DoubleArray array2 = array1; // 注意不是两对象之间的简单赋值 如：array2 = array1
```

（2）函数调用时，对象作为实参传给形参

不建议：

```c++
void f(DoubleArray arr); //函数声明
DoubleArray array1; //对象定义
f(array1); //函数调用
```

建议：

```c++
void f(DoubleArray &arr);
DoubleArray array1;
f(array1);
```

参数传递路径：array1（实参）→arr（形参）

（3）函数返回一个对象时，会将返回的对象传给临时对象

**自定义的复制构造函数（深拷贝）**

一个对象的修改将会影响另一个对象

如果两个对象的作用域不同，当一个对象析构时，另一个对象也将丧失它的空间

```c++
DoubleArray::DoubleArray(const DoubleArray &arr)
{
    low = arr.low;
    high = arr.high;
    if (arr.storage)
    {
        storage = new double[high – low + 1];
        for (int i = 0; i < high –low + 1; ++i)
            storage[i] = arr.storage[i];
    }
}
```

## 对象的生命周期(全局、局部、静态局部)

```c++
#include<iostream>
using namespace std;

class CreateAndDestroy 
{
public:
    CreateAndDestroy(int ID)
    {
        objectID = ID; 
        cout << "constructor " << objectID << endl;
    }
    
    CreateAndDestroy(const CreateAndDestroy &a)
    {
        objectID = a.objectID;
        cout << "copy constructor " << objectID << endl;
    }
    
    ~CreateAndDestroy()
    {
        cout << "destructor " << objectID << endl;
    }
    
private:
    int objectID; 
};

CreateAndDestroy obj0(0);

void f1()
{
    cout << "f1:" << endl;
    static CreateAndDestroy obj1(1);
    CreateAndDestroy obj2(2);
}

int main()
{
    CreateAndDestroy obj3(3);
    f1();
    f1();
    return 0;
}
```

输出：

```powershell
constructor 0
constructor 3
f1:
constructor 1
constructor 2
destructor 2
f1:
constructor 2
destructor 2
destructor 3
destructor 1
destructor 0
```

**消失顺序**：

**1、局部变量先消失，然后是静态局部变量，最后是全局变量；**

**2、后创建的先消失；**

## const与类

### 常量数据成员

类的数据成员可以定义为常量，在对象生成时给出常量值，在对象的生存期内，它的值是不能改变的

### 常量对象

```c++
const Rational r1(1, 3);
```

常量对象定义后不能被修改

### 常量成员函数

**常量对象不能调用非常量成员函数，只能调用常量成员函数**

```c++
void display() const;
```

## 静态成员

### 静态数据成员

不必为每个对象设置一个数据成员，只需共享一个相同的值即可

不用全局变量，因为缺乏保护，可能产生名称冲突

需要定义值：

```c++
double SavingAccount::rate = 0.05;
```

### 静态成员函数

静态成员函数用于操作静态数据成员，只能访问静态数据成员，不能访问非静态数据成员，最大特点：没有this指针。

一般的成员函数能访问静态、非静态数据成员

### 静态常量数据成员

`static const`

## 友元

### 友元函数

**友元定义在类内：**

```c++
#include <iostream>
#include <cstring>
using namespace std;

class girl
{
    char name[10];
    int age;

public:
    girl(const char *n, int d)
    {
        strcpy(name, n);
        age = d;
    }
    friend void disp(girl &x)
    {
        cout << x.name << " " << x.age << endl;
    }
};

int main()
{
    girl g("Alice", 20);
    disp(g);
    return 0;
}
```

**友元定义在类外：**

（这没有用到友元）


### 友元成员

是其他类的成员函数。

可以访问friend声明语句所在类的私有成员和公有成员。

类A的成员函数作为类B的友元函数时，必须先定义类A，再定义类B。在定义类A和B前必须先声明类B。

格式：friend  函数返回类型  类名标识符::

        函数名(参数列表)； 

### 友元类

整个类作为另一个类的友元。

当A类被说明为类B的友元时，类A的所有函数都是类B的友元函数

声明方法：

```c++
class Y{
    …
};
class X{
    …
    friend Y;    //或friend class Y
    …
};
```

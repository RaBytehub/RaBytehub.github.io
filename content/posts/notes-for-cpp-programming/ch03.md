# 分支结构

> 分支结构用于让程序根据条件选择不同路径。本章整理关系表达式、逻辑运算符、条件语句和随机数的基础用法。

## 关系表达式

只有赋值运算符是右结合，其余是左结合

**优先级：算术运算符>关系运算符>赋值运算符**

关系运算符内部，== 和 != 优先级较低

## 逻辑运算符

逻辑运算符：逻辑非>算术运算符>逻辑与>逻辑或

**优先级： ! > 关系运算符 > && > ||**

短路求值：

逻辑表达式在执行时，先处理左边，如左边已能决定此逻辑表达式的结果，则右边不执行

在&&表达式中，把false可能性较大的条件放在左边

在||表达式中，把true可能性较大的条件放在左边

节省计算量

## 运算符优先级

### 表格转写：运算符优先级要点

C++ 运算符优先级从高到低大致如下：

| 类别 | 运算符 |
| --- | --- |
| 后缀/成员访问 | `()`、`[]`、`.`、`->`、后置 `++`、后置 `--` |
| 单目运算 | 前置 `++`、前置 `--`、`!`、`~`、`+`、`-`、`*`、`&`、`sizeof` |
| 算术 | `*`、`/`、`%` 高于 `+`、`-` |
| 关系 | `<`、`<=`、`>`、`>=`、`==`、`!=` |
| 逻辑 | `&&` 高于 `||` |
| 条件 | `?:` |
| 赋值 | `=`、`+=`、`-=`、`*=`、`/=`、`%=` |
| 逗号 | `,` |

复杂表达式建议主动加括号，不要依赖读者记忆优先级。

## 条件判断

if-else

判断是否是闰年：

```c++
bool result;
result = (year % 4 == 0 && year % 100 != 0)|| year % 400 == 0;
cout << (result ? "yes" : "no");
```

配对原则：每个else子句是和在它之前**最近**的一个没有else子句的if语句配对

条件表达式：

```c++
cout << (flag ? "true" : "false");
```

## 随机数生成

```c++
#include <cstdlib>   //包含伪随机数生成函数和种子设置函数，隐式包含在编译器里面
#include <ctime>     //包含取系统时间函数
#include <iostream>
using namespace std;
int main()
{
    int num1, num2, op, result1, result2;
    //num1,num2:操作数, op:运算符,result1,result2: 结果

    srand(time(NULL));                           //随机数种子初始化

    num1 = rand() % 10; //生成运算数
    num2 = rand() % 10; //生成运算数
    op = rand() % 4;    //生成运算符 0--+, 1-- -, 2--*, 3-- /
    return 0;
}
```

生成不同的运算数据：将生成的随机数映射到0-9之间

```c++
rand()%10;
rand()*10/(RAND_MAX+1)
```

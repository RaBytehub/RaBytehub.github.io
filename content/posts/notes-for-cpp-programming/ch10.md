# 组合与继承

> 组合与继承是构造复杂类型的两种核心方式。本章整理对象成员、继承访问控制、多态和抽象类。

## 组合

基类构造函数的调用方式

如果派生类对象构造时对包含的基类对象是用基类默认的构造函数初始化的，那么在派生类构造函数的初始化列表中可以不出现基类构造函数调用。

```c++
class Base {
public:
    Base(int x) {}   // 只有带参构造，没有默认构造
};

class Derived : public Base {
public:
    // 错误： 错误：编译器不知道如何初始化基类部分
    Derived() {} 
    
    // 正确： 正确：显式调用基类带参构造
    Derived() : Base(10) {}
};
```

## 继承

派生类成员的访问属性

### 图示转写：继承方式与访问控制

派生类继承基类时，基类成员在派生类中的可见性受继承方式影响：

| 继承方式         | 基类 `public` 成员 | 基类 `protected` 成员 | 基类 `private` 成员 |
| ---------------- | ------------------ | --------------------- | ------------------- |
| `public` 继承    | 仍为 `public`      | 仍为 `protected`      | 派生类不可直接访问  |
| `protected` 继承 | 变为 `protected`   | 仍为 `protected`      | 派生类不可直接访问  |
| `private` 继承   | 变为 `private`     | 变为 `private`        | 派生类不可直接访问  |

最常用的是 `public` 继承，用来表达"派生类是一种基类"。

基类的对象引用派生类的对象

### 代码转写：派生类访问基类成员

```cpp
class Base {
protected:
    int x;
    int y;
public:
    void setx(int k);
    void sety(int k);
};

class Derived : public Base {
    int z;
public:
    void setxyz(int i, int j, int k)
    {
        setx(i);
        y = j;
        z = k;
    }
};
```

派生类可以访问基类的 `protected` 成员，但不能直接访问基类的 `private` 成员。

### 派生类对象的构造

**派生类不继承基类的构造函数、析构函数，但是派生类的构造函数、析构函数和赋值运算符能调用基类的构造函数、析构函数**

**由于派生类继承了其基类的成员，也包含了新增的数据成员，所以在建立派生类的实例对象时，必须初始化基类继承的数据成员，也需要初始化新增的数据成员**

**基类成员的初始化由基类的构造函数完成，派生类的构造函数必须通过其初始化列表调用基类的构造函数**

**派生类的构造函数体只负责初始化新增的数据成员**

### 派生类对象的析构

**派生类对象析构时，也必须析构基类对象**
**==派生类对象的析构顺序与初始化顺序相反==**
**析构过程：**
**1）先执行派生类的析构函数，析构自己新增的数据成员**
**2）如果有对象成员，然后自动调用对象成员的析构函数**
**3）最后自动调用基类的析构函数**

### 重定义基类的函数 

派生类是基类在数据和功能上的扩展
派生类中成员函数名可能会和基类的成员函数名相同
若只是函数名相同而原型不同，则系统认为派生类中有两个重载函数
若原型完全相同，则派生类的函数会覆盖基类的函数，这称为重定义基类的成员函数

override, final

### 代码转写：派生类定义示例

从圆类派生球类时，可以复用半径并新增球体的表面积和体积计算：

```cpp
class Ball : public Circle {
public:
    Ball(double r = 0) : Circle(r) {}
    double area() const { return 4 * Circle::area(); }
    double volume() const { return 4 * 3.14 * radius * radius * radius / 3; }
};
```

从圆类派生圆柱类时，需要增加高度：

```cpp
class Cylinder : public Circle {
    double height;
public:
    Cylinder(double r = 0, double h = 0) : Circle(r), height(h) {}
    double geth() const { return height; }
    double area() const { return 2 * Circle::area() + circum() * height; }
    double volume() const { return Circle::area() * height; }
};
```

### 基类指针(引用)指向(引用)派生类对象

### 图示转写：基类指针或引用指向派生类对象

基类指针或引用可以指向派生类对象，但通过它只能访问基类中声明过的成员：

```cpp
Derived d;
Base* bp = &d;
bp->setx(3);   // 可以
// bp->z = 4;  // 不可以，Base 中没有 z
```

如果希望通过基类指针调用派生类重写后的函数，需要把基类函数声明为 `virtual`。

## 多态性

**多态性**：不同对象收到相同的消息时产生的动作不同
多态的实现：
静态联编：编译时已确定用哪一个函数实现某一动作，比如函数重载和运算符重载
动态联编：直到运行时才确定用哪一个函数来实现动作，因为存在类型的兼容性，所以有些函数只有在运行时才能确定是调用父类的还是子类的函数。
在C++中，使用**虚函数+指向不同派生类对象的基类指针**来实现

```c++
#include <iostream>
using namespace std;

class Shape {
public:
    virtual void printShapeName() { cout << "Shape" << endl; }
    virtual ~Shape() {}  // 虚析构函数
};

class Point : public Shape {
public:
    virtual void printShapeName() { cout << "Point" << endl; }
};

class Circle : public Point {
public:
    virtual void printShapeName() { cout << "Circle" << endl; }
};

class Cylinder : public Circle {
public:
    virtual void printShapeName() { cout << "Cylinder" << endl; }
};

int main() {
    Point aPoint;
    Circle aCircle;
    Cylinder aCylinder;

    // ========== 情况1：对象数组（切片，无多态）==========
    cout << "=== 对象数组（切片）===" << endl;
    Shape shapes[3] = {aPoint, aCircle, aCylinder};
    for (int i = 0; i < 3; i++)
        shapes[i].printShapeName();  // 全部输出 Shape

    // ========== 情况2：指针数组（多态）==========
    cout << "\n=== 指针数组（多态）===" << endl;
    Shape* pShape[3] = {&aPoint, &aCircle, &aCylinder};
    for (int i = 0; i < 3; i++)
        pShape[i]->printShapeName();  // 输出 Point, Circle, Cylinder

    // ========== 情况3：引用（多态）==========
    cout << "\n=== 引用（多态）===" << endl;
    Shape& ref1 = aPoint;
    Shape& ref2 = aCircle;
    Shape& ref3 = aCylinder;
    ref1.printShapeName();  // 输出 Point
    ref2.printShapeName();  // 输出 Circle
    ref3.printShapeName();  // 输出 Cylinder

    return 0;
}
```

**为什么需要虚析构函数**

**构造函数不能是虚函数，但析构函数可以是虚函数，而且最好是虚函数** 
如果没有将析构函数定义为虚函数，当用基类指针析构一个派生类对象时，只会调用基类的析构函数
造成派生类新增的数据成员没有析构，有可能造成**内存泄漏**

当把析构函数定义为虚函数时
当用基类指针析构一个派生类对象时，找到基类的析构函数。由于基类的析构函数是虚函数，又会找到派生类的析构函数并调用派生类的析构函数，而**派生类的析构函数会自动调用父类的析构函数，从而依次完成对整个派生类对象的正确析构**

```c++
#include <iostream>
using namespace std;

class Shape {
public:
    virtual ~Shape() {   // 正确： 虚析构函数
        cout << "Shape 析构" << endl;
    }
};

class Point : public Shape {
private:
    int* pData;
public:
    Point() {
        pData = new int(100);
        cout << "Point 构造" << endl;
    }
    
    ~Point() {           // 自动成为虚函数（可加 virtual，也可不加）
        delete pData;
        cout << "Point 析构" << endl;
    }
};

int main() {
    Shape* ptr = new Point();
    delete ptr;  // 正确： 正确释放
    
    return 0;
}
```

## 纯虚函数与抽象类

**纯虚函数：一个在基类中没有具体实现的虚函数**
在派生类里需要重定义实现基类的纯虚函数或继续说明为纯虚函数

```c++
virtual 类型 函数名(参数表) = 0;
```

**如果一个类中至少有一个纯虚函数，则该类被称为抽象类**
抽象类不能定义对象，因为包含无法运行的纯虚函数，只能定义指针

指针的作用是指向派生类对象

抽象类的意义：规范由它派生的派生类的行为（确保派生类都有纯虚函数所要求的行为)

# 绪论

> 这篇文章整理 C++ 学习前需要掌握的计算机基础：存储单位、进制、语言层次、程序从源代码到可执行文件的过程。

## 基本

内存的最小单元是bit，一个bit存储一个二进制位（0/1）。一般8个bit组成一个byte

在一般的机器中，内存按字节（byte）编址，内存大小也是按字节计量

### 图示转写：冯诺依曼体系结构

经典计算机硬件由输入设备、存储器、运算器、控制器和输出设备组成。其中运算器和控制器合称为 CPU。

程序执行的大致过程是：

1. 输入设备把程序和数据装入计算机。
2. 存储器保存程序、数据以及运算的中间结果和最终结果。
3. 控制器根据指令控制程序运行，并协调其他部件工作。
4. 运算器完成算术运算和逻辑运算。
5. 输出设备把处理结果展示给用户。

位：计算机中的**最小**的存储和处理单位，所有数据的处理和存储都是以bit为基础，例如算数运算、逻辑运算等。一个bit只能表示0和1

字节：计算机数据存储和处理的**基本**单位，通常为8位，是一种度量方式，类似于分钟、平方米（内存地址是对字节进行编号）

字长：计算机处理器一次运算中能够处理的**最大数据宽度**，由硬件设备决定，如32位处理器（单次可传输32位信息）——数据总线的宽度

## 高级语言和低级语言的区别

### 表格转写：低级语言与高级语言的区别

| 维度 | 机器语言 | 汇编语言 | 高级语言 |
| --- | --- | --- | --- |
| 抽象程度 | 直接使用二进制指令 | 使用助记符表示指令 | 接近自然语言和数学表达式 |
| 可读性 | 很差 | 较差 | 较好 |
| 开发效率 | 很低 | 较低 | 高 |
| 执行效率 | 最高 | 高 | 需要编译器优化 |
| 硬件依赖 | 直接依赖 CPU | 依赖特定 CPU | 跨平台能力更强 |
| 典型形式 | `10110000 01100001` | `MOV A, 0x61` | `cout << "Hello";` |

## 程序（从源程序到可执行程序）

### 图示转写：从源程序到可执行程序

C++ 源代码通常经历以下阶段生成可执行文件：

1. 预处理：处理 `#include`、`#define`、条件编译等，生成预处理后的源文件。
2. 编译：把 C++ 源代码翻译成汇编代码。
3. 汇编：把汇编代码翻译成目标文件。
4. 链接：把目标文件和库文件组合起来，生成可执行程序。

常见的命令形式如下：

```bash
g++ hello.cpp -o hello
./hello
```

## 补充：几个容易混淆的概念

| 概念 | 重点 |
| --- | --- |
| bit | 二进制位，只能表示 `0` 或 `1`。 |
| byte | 字节，通常等于 8 bit，是内存编址和容量描述的基本单位。 |
| 字长 | CPU 一次可以处理的数据宽度，例如 32 位、64 位。 |
| 地址空间 | 能表示多少个不同地址，取决于地址位数。 |

例如 16 位地址最多表示 `2^16` 个地址；如果按字节编址，则最多能寻址 `2^16` 个字节。

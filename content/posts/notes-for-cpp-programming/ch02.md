# 程序的基本组成

> 这一章关注 C++ 程序的基本骨架，以及变量、常量和基础数据类型。理解这些内容后，才能稳定地阅读和编写简单程序。

## 程序的基本组成

### 代码图转写：Hello World 程序组成

一个最小 C++ 程序通常包含注释、预处理、命名空间和主函数：

```cpp
// File: helloWorld.cpp
// This program prints a message.

#include <iostream>
using namespace std;

int main()
{
    cout << "Hello world!" << endl;
    return 0;
}
```

其中 `#include <iostream>` 引入输入输出库，`using namespace std;` 让代码可以直接使用标准库名称，`main` 是程序入口。

注释、编译预处理、名字空间、主程序

### 编译预处理：

	**库包含**：用#include实现，表示程序使用了某个库
	
	**宏定义**：用#define实现。
	
	**条件编译**：根据 #ifdef 或 #ifndef 等条件指令决定是否编译某部分代码。
	
	宏包括：
	
	不带参数的宏，通常用来定义符号常量
	
	带参数的宏，用来定义一些较为复杂的操作
	
	宏定义好处：增强代码可读性，一处改，处处改

### 名字空间

### 表格转写：命名空间的三种使用方式

| 方法 | 示例 | 说明 |
| --- | --- | --- |
| 直接使用完全限定名 | `std::cout << "Hello";` | 不引入命名空间，写法清晰，但代码较长。 |
| 使用 `using` 声明单个名字 | `using std::cout;` | 只引入需要的名字，冲突风险较小。 |
| 使用 `using namespace` | `using namespace std;` | 引入整个命名空间，初学阶段方便，但大型项目中容易产生命名冲突。 |
| 命名空间嵌套 | `using namespace one::other;` | 适合组织更复杂的模块层级。 |

### 主程序

函数头 `main`

函数体 `{...}`

**`<<` （流插入运算符）**：常用于**输出**

**`>>` （流提取运算符）**：常用于**输入**

`endl`：换行并**强制刷新缓冲区**； 换行符也可使用`\n`

## 变量与常量

C++中的每个变量都有其数据类型，决定了：变量占内存空间的大小和布局方式、该空间能存储的值的范围、变量能参与的运算

C++中的变量分类：

内置数据类型（面向过程部分） ——基本类型—— 程序设计思想与方法C

自定义数据类型（面向对象部分）——复合类型

### 整型

### 表格转写：整型数据类型

| 类型 | 常见字节数 | 典型取值范围 |
| --- | ---: | --- |
| `short` | 2 | `-32768` 到 `32767` |
| `int` | 4 | 约 `-2^31` 到 `2^31 - 1` |
| `long` | 4 或 8 | 与平台相关 |
| `long long` | 8 | 约 `-2^63` 到 `2^63 - 1` |

整型溢出是常见错误。例如 32 位有符号 `int` 的最大值是 `2147483647`，继续加 1 会发生溢出。变量占用空间可以用 `sizeof` 查看：

```cpp
cout << sizeof(int) << endl;
```

内置类型的全局变量（函数外部定义的变量）默认初始值为0

局部变量（函数内部定义的变量）不初始化

#### 整型数的表示——**码制**

原码、反码、补码

原码

反码：符号位保留，原码取反

补码：正数的补码与原码相同，负数的补码为该数的反码加1

整数在计算机内部通常用补码表示 

**按位取反运算符 `~`**：数学意义上计算结果等于 `-(x + 1)` （因为在计算机中整数通常以**补码**形式存储）

**按位与运算符 `&`**：全1则1，有0则0

**按位异或运算符 `^`**：相同则0，不同则1

**按位或运算符 `|`**：有1则1，全0则0

### 实型

```c++
#include <iomanip>   //用于setprecision
cout << setprecision(15);
cout << PI << endl;

cout << fixed << setprecision(15) << PI << endl;
```

fixed作用：

- **强制使用定点十进制表示法**（例如 `3.14159`），而不是科学计数法（例如 `3.14159e+00`）。
- **改变 `setprecision(n)` 的含义**：在没有 `fixed` 时，`setprecision(n)` 表示 **总共 n 位有效数字**；加上 `fixed` 后，`setprecision(n)` 表示 **小数点后固定输出 n 位**。
